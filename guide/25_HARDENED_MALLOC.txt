## 25_HARDENED_MALLOC

## hardened_malloc is the hardened memory allocator from GrapheneOS. Preloaded into every process, it replaces glibc's malloc with one built against heap exploitation: guard pages, extensive randomization, and quarantine of freed memory. Heap bugs become much harder to turn into code execution.
## It is great hardening, but it breaks Electron apps, Mullvad in this case. I did not create something to exclude Mullvad from the system-wide allocation. You can install and enable the allocator. It might work with Mullvad. At the time of writing, it does not work.
## Download the signing key of Daniel Micay (thestinger), the hardened_malloc author:
torsocks wget https://github.com/thestinger.gpg
## Inspect the key and compare the fingerprint against a second source before trusting it:
gpg --keyid-format long --with-fingerprint thestinger.gpg

## Import the key:
gpg --import thestinger.gpg

## Clone, verify the release tag, and build:
cd ~/Downloads
torsocks git clone https://github.com/GrapheneOS/hardened_malloc.git
cd hardened_malloc
git tag --verify 8
make
make VARIANT=light

## Install the library into /usr/lib/. This location maximizes compatibility: the bare library name resolves through the default loader search path, and AppArmor abstractions commonly allow reads under /usr/lib/, while exotic paths cause preload failures:
sudo mv out/libhardened_malloc.so /usr/lib/libhardened_malloc.so
sudo mv out-variant/libhardened_malloc-light.so /usr/lib/libhardened_malloc-light.so
sudo chown root:root -R /usr/lib/libhardened_malloc.so
sudo chown root:root -R /usr/lib/libhardened_malloc-light.so
sudo chmod 644 /usr/lib/libhardened_malloc.so
sudo chmod 644 /usr/lib/libhardened_malloc-light.so

## Check the permissions. The library must be owned by root and writable by root only. It is preloaded into every process, setuid binaries included, so a library writable by anyone is a root compromise waiting to happen:
ls -l /usr/lib/libhardened_malloc.so

## The output must show root root and a mode of 644 (rw-r--r--).
## Enable the allocator system-wide:
sudo vim /etc/ld.so.preload
```ini
/usr/lib/libhardened_malloc.so
```

# You can enable hardened_malloc system-wide for root and user applications (this will break Mullvad GUI, the mullvad-daemon, Kill switch/Lockdown and mullvad-cli remain to work) with:
sudo chmod 644 /etc/ld.so.preload

# You can enable hardened_malloc system-wide only for root applications (like mullvad-daemon) with
sudo chmod 600 /etc/ld.so.preload

# You can also use or try the light variant
sudo vim /etc/ld.so.preload
```ini
/usr/lib/libhardened_malloc-light.so.so
```
sudo chmod 644 /etc/ld.so.preload


## Run the test suite from the repository directory to confirm the allocator works on this hardware:
cd ~/Downloads/hardened_malloc
make test

## disable hardened_malloc by deleting the line "/usr/lib/libhardened_malloc.so"
sudo vim /etc/ld.so.preload
