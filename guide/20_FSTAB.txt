## 20_FSTAB

## These mount options harden the partitions from the installation.
## Open the fstab:
sudo vim /etc/fstab
## The UUIDs are left out here on purpose. Keep the ones from your generated fstab and only adjust the options:
```ini
# Static information about the filesystems.
# See fstab(5) for details.

# <file system> <dir> <type> <options> <dump> <pass>
# /dev/mapper/archvg-root
UUID=	/         	ext4      	rw,relatime	0 1

# /dev/nvme0n1p1
UUID=	/boot/efi 	vfat      	rw,relatime,fmask=0077,dmask=0022,codepage=437,iocharset=ascii,shortname=mixed,utf8,errors=remount-ro	0 2

# /dev/mapper/archvg-var
UUID=	/var      	ext4      	rw,relatime,nosuid,nodev	0 2

# /dev/mapper/archvg-home
UUID=	/home     	ext4      	rw,relatime,nosuid,nodev,noexec	0 2

# /dev/mapper/archvg-home--user
UUID=	/home/user	ext4      	rw,relatime,nosuid,nodev,noexec	0 2

/dev	/dev	/dev	devtmpfs	rw,remount,nosuid,noexec	0	0
```

## TMPFS: LESS TRACES ON THE DISK
## Log and cache folders can be mounted into RAM. After every shutdown their content is gone: less timestamps of your online activity, no crash logs, no cached files on the disk.
## The price: after a crash you have no logs to debug from.

## Add these lines to the same fstab:
```ini
/dev/shm	/dev/shm		tmpfs	rw,nosuid,nodev,noexec	0 0
tmpfs	/tmp		tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid	0 0
tmpfs	/var/tmp	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid	0 0
tmpfs	/var/log	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid,mode=1755	0 0
tmpfs	/home/user/.cache	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid,uid=1001,gid=1001,mode=1700	0 0
tmpfs	/home/admin/.cache	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid,uid=1000,gid=1000,mode=1700	0 0
tmpfs	/root/.cache	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid,mode=1700	0 0

# On Arch Linux, downloaded packages live in /var/cache/pacman/pkg, this folder grows far too large for RAM:
#tmpfs	/var/cache	tmpfs	rw,size=1G,nr_inodes=5k,noexec,nodev,nosuid,mode=1755	0 0
```

## After adding the tmpfs lines and before rebooting, empty these folders. A tmpfs mount hides the old files, it does not delete them from the encrypted disk underneath.
sudo rm -r /tmp/*
sudo rm -r /var/tmp/*
sudo rm -r /var/log/*
sudo rm -r /home/user/.cache/*
sudo rm -r /home/admin/.cache/*
sudo rm -r /root/.cache/*


## If you use the admin account only for updates, you can add noexec to /dev/mapper/archvg-home line as well.
